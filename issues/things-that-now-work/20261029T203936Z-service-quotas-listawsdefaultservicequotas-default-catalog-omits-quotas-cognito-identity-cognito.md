## Operation
ListAWSDefaultServiceQuotas

## Description
BUNDLE OF 8 CAUSES (one per ServiceCode). ListAWSDefaultServiceQuotas answers HTTP 200 but serves its Quotas list from a hand-written static default-quota table in the service-quotas crate instead of AWS's published default-quota catalog. For each ServiceCode below the table holds only a handful of rows, so most of that service's real default quotas are absent from a successful response, and the row set additionally contains CamelCase quota codes that appear in no recorded AWS response for the ServiceCode.

Same component as open issue 20261029T192055Z-service-quotas-listawsdefaultservicequotas-serves-a-hand-written-default-quota-table.md, whose replay keys cover a DISJOINT set of 27 other ServiceCodes; none of the 8 below is carried by it, so each needs its own fixture replayed before it can be closed.

Shared statement of the defect, applied per cause below -- AWS: ListAWSDefaultServiceQuotas returns the complete AWS default-quota set for the requested ServiceCode (Smithy: ListAWSDefaultServiceQuotas.ServiceCode required @length 1..63 @pattern ^[a-zA-Z][a-zA-Z0-9-]{1,63}$; output Quotas -> ServiceQuotaListDefinition; paginated NextToken/MaxResults; ServiceQuota members QuotaCode @length 1..128, Description @length 0..350, Adjustable default false, plus the optional Period, UsageMetric and QuotaContext structures). Every row in every recording in this corpus is keyed on an L-XXXXXXXX quota code. Why (every cause): a client enumerating default quotas to resolve a code, read a default Value or test Adjustable is told the quota does not exist, so capacity logic and any follow-up GetServiceQuota / RequestServiceQuotaIncrease on a real AWS quota code cannot be reached; a CamelCase code read back out is an identifier real AWS rejects. Fix (every cause): the static default-quota catalog data the ListAWSDefaultServiceQuotas handler reads in the service-quotas crate -- populate it from AWS's catalog for these ServiceCodes, keyed on the real quota codes and carrying the Period/UsageMetric/QuotaContext blocks the rows have in AWS.
