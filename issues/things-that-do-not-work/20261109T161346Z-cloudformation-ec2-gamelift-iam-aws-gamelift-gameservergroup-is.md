# cloudformation__ec2__gamelift__iam: AWS::GameLift::GameServerGroup is not a registered resource type — CreateStack refuses every game-server-group template with "Unrecognized resource types"

> _Note: this issue was identified against the code base at commit `87192d19b1d499e8425d8cf541553378b48cc888`. If you are an issue fixer working on this, the code base you are currently working in can have drifted, so you might need to trace the issue back to the current code base._

## Operation
CreateStack

## Description
Cause 1 of 1: CloudFormation's template resource-type registry does not contain AWS::GameLift::GameServerGroup, so a template that declares one is refused outright at CreateStack and no GameLift game server group can ever be provisioned, read back, validated or deleted through a stack. Failing checks: cloudformation__ec2__gamelift__iam.deploy-gamelift-game-server-group-round-trip-and-delete, cloudformation__ec2__gamelift__iam.deploy-gamelift-game-server-group-invalid-instance-type-rejected-and-rolled-back.

AWS: AWS::GameLift::GameServerGroup is a first-class, registry-backed CloudFormation resource type. CreateStack on a well-formed template that declares it (alongside AWS::EC2::VPC/Subnet/LaunchTemplate and an AWS::IAM::Role) is ACCEPTED (HTTP 200, a StackId is returned) and the stack proceeds to CREATE_COMPLETE; the type is never reported as unrecognized. Its handler creates the group through GameLift CreateGameServerGroup (Smithy: CreateGameServerGroup.GameServerGroupName required, @length 1..128, @pattern ^[a-zA-Z0-9-\.]+$; RoleArn required @pattern ^arn:.*:role\/[\w+=,.@-]+$; MinSize required @range min 0; MaxSize required @range min 1; LaunchTemplate required; InstanceDefinitions required @length 2..20; VpcSubnets @length 1..20; Tags @length 0..200; errors ConflictException/InvalidRequestException/LimitExceededException/UnauthorizedException, all HTTP 400). On the happy path Ref on the resource resolves to the group's GameServerGroupArn and Fn::GetAtt <res>.AutoScalingGroupArn resolves to the backing Auto Scaling group ARN; the group is then visible through GameLift ListGameServerGroups and DescribeGameServerGroup with GameServerGroupArn, AutoScalingGroupArn, RoleArn, the templated InstanceDefinitions in order and Status ACTIVE, and the stack-level tag plus the resource's own Tags are readable through gamelift ListTagsForResource (the ARN shape is arn:<partition>:gamelift:<region>:<account>:gameservergroup/<name>; the account, region and name are per-run values, the shape is the requirement). On the negative path an InstanceDefinitions entry whose instanceType is outside GameLift's supported enum is refused by the SERVICE call, so the stack ends ROLLBACK_COMPLETE and the group resource's CREATE_FAILED ResourceStatusReason is a registry-handler reason of the form Resource handler returned message: "<service message>" (RequestToken: <uuid>, HandlerErrorCode: InvalidRequest), where <service message> is GameLift's own enum-violation text "1 validation error detected: Value at 'instanceDefinitions.<n>.member.instanceType' failed to satisfy constraint: Member must satisfy enum value set: [<the supported instance-type enum, comma separated>] (Service: GameLift, Status Code: 400, Request ID: <id>) (SDK Attempt Count: <n>)" — the fixed text is "1 validation error detected: Value at '", "' failed to satisfy constraint: Member must satisfy enum value set: [", the "(Service: GameLift, Status Code: 400, Request ID: ...)" suffix and the HandlerErrorCode InvalidRequest; the member path index, the enum list and the request id/attempt count are per-request/per-model values. After the rollback no group exists: ListGameServerGroups does not list the name and DescribeGameServerGroup answers NotFoundException "Game server group <group-arn> does not exists on account" (fixed text "Game server group " / " does not exists on account" around the ARN the group would have had).

Emulator: CreateStack is REFUSED with HTTP 400 ValidationError and the message "Template format error: Unrecognized resource types: [AWS::GameLift::GameServerGroup]" (fixed text "Template format error: Unrecognized resource types: [" ... "]", the bracketed list being the unrecognized types of the submitted template). No StackId is returned and no stack exists, so every downstream observation — Ref/AutoScalingGroupArn resolution, the GameLift round trip, tag propagation, the enum-violation rollback reason and the post-rollback absence — is unreachable.

Why: a client that deploys GameLift FleetIQ game server groups by template (console, CLI, CDK, Terraform's CFN resources) cannot create or manage one at all, and the refusal arrives as a template-FORMAT error, which tells the client its template is malformed rather than that the provider is missing — so no retry or template edit can ever succeed. Negative tests invert as well: a failure AWS reports as a per-resource CREATE_FAILED handler reason after a rollback is instead reported before any stack exists, with a different code, status and message.

Fix: the CloudFormation service's template resource-type registry (the table template validation consults to decide a type is recognized) must register AWS::GameLift::GameServerGroup, and a provisioning handler for it must be added that calls gamelift CreateGameServerGroup/DescribeGameServerGroup/DeleteGameServerGroup, publishes Ref (the group ARN) and the AutoScalingGroupArn attribute from GameLift's own state, propagates stack and resource tags, and surfaces the service's InvalidRequestException as a CREATE_FAILED registry-handler reason with HandlerErrorCode InvalidRequest so the stack rolls back and leaves no group behind.

Traces: see trace_ids; both checks fail identically on the first CreateStack call, before any GameLift or EC2 call is made.

## Evidence
Expected (AWS): cfn.create_stack(TemplateBody=<template with Resources.Group of Type AWS::GameLift::GameServerGroup>, Capabilities=["CAPABILITY_NAMED_IAM"]) -> HTTP 200 with a StackId; DescribeStacks reaches CREATE_COMPLETE; Outputs carry Ref == the group's GameServerGroupArn and Fn::GetAtt Group.AutoScalingGroupArn == the ASG ARN; DescribeGameServerGroup reports (GameServerGroupArn, AutoScalingGroupArn, RoleArn, InstanceDefinitions, Status=="ACTIVE"). For the unsupported-instance-type template the stack ends ROLLBACK_COMPLETE and the Group resource's CREATE_FAILED reason is Resource handler returned message: "1 validation error detected: Value at 'instanceDefinitions.1.member.instanceType' failed to satisfy constraint: Member must satisfy enum value set: [...] (Service: GameLift, Status Code: 400, Request ID: <id>) (SDK Attempt Count: <n>)" (RequestToken: <uuid>, HandlerErrorCode: InvalidRequest), after which ListGameServerGroups omits the name and DescribeGameServerGroup answers NotFoundException "Game server group <arn> does not exists on account".

Actual (emulator): botocore.exceptions.ClientError: An error occurred (ValidationError) when calling the CreateStack operation: Template format error: Unrecognized resource types: [AWS::GameLift::GameServerGroup]

## Steps to Reproduce
1. Build and boot the emulator.
2. aws cloudformation create-stack --stack-name gsg --capabilities CAPABILITY_NAMED_IAM --template-body '{"AWSTemplateFormatVersion":"2010-09-09","Resources":{"Vpc":{"Type":"AWS::EC2::VPC","Properties":{"CidrBlock":"10.126.0.0/16"}},"Subnet":{"Type":"AWS::EC2::Subnet","Properties":{"VpcId":{"Ref":"Vpc"},"CidrBlock":"10.126.1.0/24"}},"LaunchTemplate":{"Type":"AWS::EC2::LaunchTemplate","Properties":{"LaunchTemplateData":{"InstanceType":"c5.large"}}},"GsgRole":{"Type":"AWS::IAM::Role","Properties":{"AssumeRolePolicyDocument":{"Version":"2012-10-17","Statement":[{"Effect":"Allow","Principal":{"Service":["gamelift.amazonaws.com","autoscaling.amazonaws.com"]},"Action":"sts:AssumeRole"}]}}},"Group":{"Type":"AWS::GameLift::GameServerGroup","Properties":{"GameServerGroupName":"demo-gsg","RoleArn":{"Fn::GetAtt":["GsgRole","Arn"]},"MinSize":0,"MaxSize":1,"LaunchTemplate":{"LaunchTemplateId":{"Ref":"LaunchTemplate"}},"InstanceDefinitions":[{"InstanceType":"c5.large"},{"InstanceType":"c4.large"}],"VpcSubnets":[{"Ref":"Subnet"}],"DeleteOption":"FORCE_DELETE"}}}}'
3. Observe HTTP 400 ValidationError "Template format error: Unrecognized resource types: [AWS::GameLift::GameServerGroup]" instead of an accepted CreateStack that reaches CREATE_COMPLETE.
4. Repeat with one InstanceDefinitions entry set to "t3.micro": AWS rolls the stack back with the GameLift enum-violation handler reason on the Group resource; the emulator refuses the CreateStack with the same unrecognized-type error.
