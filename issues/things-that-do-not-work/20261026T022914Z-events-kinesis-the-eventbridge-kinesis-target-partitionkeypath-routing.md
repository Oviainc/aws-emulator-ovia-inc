# events__kinesis: the EventBridge Kinesis-target PartitionKeyPath routing contract is still ungraded — the blocking kinesis data-plane stub has moved from GetShardIterator to GetRecords, which answers 501 NotImplemented

> _Note: this issue was identified against the code base at commit `6a69e82c081230a77b3ef80ecf5b0e8bc7e37fe8`. If you are an issue fixer working on this, the code base you are currently working in can have drifted, so you might need to trace the issue back to the current code base._

## Operation
GetRecords

## Description
One root cause. Cause count: 1.

=== Cause 1 of 1: kinesis GetRecords is an unimplemented scaffold stub, so the EventBridge Kinesis target's PartitionKeyPath routing (and the eventId fallback of a sibling target without KinesisParameters) can never be observed ===

AWS: Smithy (services/service-com-amazonaws-kinesis-kinesis-20131202/smithy-model/com-amazonaws-kinesis-kinesis-20131202.json) models kinesis GetRecords with required input member ShardIterator (len 1..512), optional Limit (range 1..10000), StreamARN (len 1..2048, pattern ^arn:aws.*:kinesis:.*:\d{12}:stream/\S+$) and DryRun, and output members Records (required), NextShardIterator (len 1..512), MillisBehindLatest (range 0..) and ChildShards, on HTTP 200. Its ONLY modeled failures are AccessDeniedException, DryRunOperationException, ExpiredIteratorException, InvalidArgumentException, the five KMS* errors, KMSThrottlingException, ProvisionedThroughputExceededException and ResourceNotFoundException (all HTTP 400) plus InternalFailureException (HTTP 500). `NotImplemented` is not a member of this operation's error set at all, and for a live, ACTIVE stream read from a valid TRIM_HORIZON iterator the correct answer is not an error: it is 200 with the records written to that shard (an empty Records list if none have arrived yet). The EventBridge side the check grades: Smithy (com.amazonaws.eventbridge#KinesisParameters) models one required member PartitionKeyPath (@length 0..256), documented as "This object enables you to specify a JSON path to extract from the event and use as the partition key for the Amazon Kinesis data stream, so that you can control the shard to which the event goes. If you do not include this parameter, the default is to use the eventId as the partition key." So the record a PartitionKeyPath target writes must be keyed by the value that JSON path selects from the delivered envelope, evaluated PER EVENT (two events carrying different $.detail.tenant values must land under two different partition keys), and a sibling target on the same rule and the same stream with NO KinesisParameters must key its record on the delivered envelope's event id. Recorded behavior only, for the two refinements the model does not state: the path-selected value arrives JSON-ENCODED (a string tenant arrives quoted, `"tenant-alpha"`, not bare), and the default target's key is the event id either bare or as the compound `{eventId}_{uuid}` — the check pins that SHAPE, not a literal. All of it is observable only through the Kinesis read path: GetShardIterator, then GetRecords.

Emulator: `botocore.exceptions.ClientError: An error occurred (NotImplemented) when calling the GetRecords operation: operation GetRecords is scaffolded but not implemented in this emulator` — HTTP 501 with error code `NotImplemented` and a message that is 100% fixed stub text parameterised only by the operation name ("operation <Op> is scaffolded but not implemented in this emulator"); it carries no value from the request or from state, where every legitimate refusal AWS has here (e.g. ResourceNotFoundException) is that error class's fixed text with the stream name/ARN taken from the request — and for this check's stream no refusal is legitimate at all. The handler is still the generated scaffold: services/service-com-amazonaws-kinesis-kinesis-20131202/src/ops/get_records.rs carries the `//! SCAFFOLDED, NOT IMPLEMENTED` marker (line 4) and its `handle` body ends in `Err(crate::scaffolded::Scaffolded::not_implemented("GetRecords"))` (line 247). Note the blocking call has MOVED: the check now gets through CreateStream, the ACTIVE wait, AddTagsToStream, DescribeStreamSummary/DescribeStream and GetShardIterator, and through the whole EventBridge setup (CreateEventBus, PutRule, PutTargets with the PartitionKeyPath target and its no-KinesisParameters twin, FailedEntryCount 0) and PutEvents, and fails on the FIRST GetRecords.

Why: a client relying on AWS's behavior gets two things wrong. First, it can never consume a stream at all — GetRecords is the read path, and the error code it receives (`NotImplemented`, HTTP 501) is not in the SDK's error model for the operation, so no except/retry clause keyed on ExpiredIteratorException, ProvisionedThroughputExceededException or ResourceNotFoundException matches, and generic retry logic retries a permanent failure. Second, PartitionKeyPath's entire purpose — controlling shard affinity, which is the reason to point an EventBridge rule at a stream rather than a queue — is left unverified: an emulator that delivers byte-perfect envelopes but keys every record under a constant, a random value, the rule name, or that resolves the path once to a constant instead of per event, is indistinguishable from a correct one, because the control plane accepts the configuration and the data plane cannot be read. The eventId fallback for a target without KinesisParameters is equally unobservable.

Fix: the kinesis data-plane read path — services/service-com-amazonaws-kinesis-kinesis-20131202/src/ops/get_records.rs, over the kinesis crate's stream/shard/record state (resolve the iterator, return the shard's records with their PartitionKey, SequenceNumber, Data and ApproximateArrivalTimestamp, a NextShardIterator and MillisBehindLatest, and refuse a stale or unknown iterator with the modeled 400 ExpiredIteratorException/ResourceNotFoundException rather than 501), then delete the SCAFFOLDED marker. The behaviour the check actually grades afterwards belongs to the eventbridge crate's Kinesis target branch (the Target/KinesisParameters delivery path: partition key = the JSON-encoded value PartitionKeyPath selects from the envelope, evaluated per event; event id when KinesisParameters is absent; two targets on the same rule and stream each writing their own record), so this needs a re-replay after the kinesis stub lands.
