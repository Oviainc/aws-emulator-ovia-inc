# ListAWSDefaultServiceQuotas rows carry another quota's metadata: shifted QuotaName, Description, Value, Unit and Adjustable across ten service codes

> _Note: this issue was identified against the code base at commit `ce1e7fa07219b3a065b602a90626dda6f8aa6c34`. If you are an issue fixer working on this, the code base you are currently working in can have drifted, so you might need to trace the issue back to the current code base._

## Operation
ListAWSDefaultServiceQuotas

## Description
The emulator's Service Quotas default-quota catalog answers ListAWSDefaultServiceQuotas with HTTP 200 and with (mostly) the right set of QuotaCodes, but the per-row metadata is attached to the WRONG QuotaCode: a code's QuotaName/Description/Value/Unit/Adjustable/UsageMetric are those of a different quota of the same service, as if the seeded rows were paired to codes in the wrong order. Several rows also drop the optional Period/UsageMetric/QuotaContext blocks or use emulator-authored Description wording. This issue bundles TEN net-new causes, one per ServiceCode, all sharing that one root cause: the per-service-code default-quota seed table, not the operation's wire framing (every cause replays 200 -> 200 and diverges only in the response body).

Smithy: ListAWSDefaultServiceQuotas(ServiceCode required) -> ListAWSDefaultServiceQuotasResponse { Quotas: list<ServiceQuota>, NextToken }; ServiceQuota members ServiceCode, ServiceName, QuotaArn, QuotaCode, QuotaName, Value (double), Unit, Adjustable (default false), GlobalQuota (default false), UsageMetric (MetricInfo), Period (QuotaPeriod), QuotaContext (QuotaContextInfo{ContextScope, ContextScopeType, ContextId, AdjustableAtLevel}), Description (max 350). The model does not enumerate quota codes or their values, so the catalog CONTENT is recorded behavior only and the recordings are the requirement. The requirement is the per-code tuple (QuotaName, Description, Value, Unit, Adjustable, GlobalQuota, Period, UsageMetric, QuotaContext, ServiceName, QuotaArn template arn:aws:servicequotas:<region>::<serviceCode>/<quotaCode>) — not any one run's region string.
